Lógica de Negocio, Guards y Eventos de Dominio

El sistema implementa arquitectura dirigida por eventos con consistencia transaccional (Transactional Outbox Pattern).

🛡️ Flujo de Ejecución de una Petición

1. Request HTTP -> Global RateLimiter (100 req/min) 2. AuthGuard -> Valida Bearer JWT 3. TenantResolver -> Inyecta TenantContext desde claims 4. PermissionGuard -> Verifica permisos (ej. 'grades.input') 5. EntitlementGuard -> Comprueba cuota del plan SaaS 6. Service -> Transacción Atómica con Outbox 7. Response 200 OK -> Logger estructurado JSON

⚡ Eventos de Dominio Versionados

🟢 StudentCreated.v1 Emitido al registrar nuevo alumno
🟢 EnrollmentConfirmed.v1 Matrícula asignada a grado/sección
🟢 PaymentCompleted.v1 Cancela pensión y actualiza balance
🟢 GradePublished.v1 Habilita libreta en portal de padres
🟢 PayrollProcessed.v1 Genera boletas y asientos de nómina

Flujo Integral del Ciclo Escolar Anual

Fase 1: Configuración & Admisiones (Enero - Febrero)
SuperAdmin provisiona -> Director abre Año 2026 -> Secretaría registra alumnos en Inicial, Primaria y Secundaria -> Tesorería emite matrícula.
Fase 2: Inicio Académico & Cobranzas (Marzo - Julio)
Docentes registran asistencia diaria -> Califican evaluaciones bimestrales -> Familias pagan pensiones y compran uniformes en tienda.
Fase 3: Cierre de Periodo, Planillas & Certificados (Noviembre - Diciembre)
Director cierra Bimestre oficial (`lockPeriod`) -> Liquida nómina mensual HR -> Emisión masiva de libretas de notas y certificados oficiales PDF.
