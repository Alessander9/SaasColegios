# 7. Fase 3 — School Core

```text
Institution
├── School
├── Campus
├── Academic Year
├── Levels
├── Grades
├── Sections
└── Classrooms
```

```text
Students
Families
Guardians

Staff
```

Ya tenemos un colegio completamente configurado.
