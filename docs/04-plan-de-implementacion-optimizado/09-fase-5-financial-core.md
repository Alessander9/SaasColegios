# 9. Fase 5 — Financial Core

Aquí pondría mucho esfuerzo.

No construiría "pensiones" como algo aislado.

Construiría:

```text
Financial Core
├── Customer Account
├── Charge
├── Invoice
├── Payment
├── Payment Method
├── Refund
├── Adjustment
├── Credit
├── Collection
├── Reconciliation
└── Ledger
```

Luego:

```text
Enrollment → Finance
Academic   → Finance
Commerce   → Finance
Activities → Finance
```

Todos consumen el mismo núcleo.
