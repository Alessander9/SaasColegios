# 5. Fase 1 — Platform Core

Ahora construimos tu SaaS.

```text
Platform
├── Tenant
├── School
├── Plan
├── Feature
├── Subscription
├── Entitlement
├── Add-on
├── Usage
└── Platform Admin
```

Ejemplo:

```text
Colegio ABC
     │
     ▼
Professional Plan
     │
     ├── Academic ✓
     ├── Finance ✓
     ├── Store ✓
     ├── Payroll ✗
     │
     └── Students
          0 / 500
```

### Resultado

Ya puedes crear un colegio y controlar exactamente **qué puede usar**.
