# 16. 🔄 Disponibilidad y recuperación

Tenemos que definir:

### RTO

¿Cuánto tiempo podemos estar caídos?

### RPO

¿Cuántos datos podríamos perder como máximo?

Ejemplo:

```text
RTO: 1 hora
RPO: 15 minutos
```

Y diseñar:

* Backups.
* Replicación.
* Disaster Recovery.
* Restauración.
* Failover.
