# 15. 📈 Escalabilidad

Tenemos que definir objetivos.

Por ejemplo:

### V1

```text
10–50 colegios
```

### V2

```text
100–500 colegios
```

### V3

```text
1,000+ colegios
```

Y para cada etapa:

* Usuarios concurrentes.
* Requests/segundo.
* Transacciones.
* Almacenamiento.
* Eventos.
* Emails.
* Archivos.
* Reportes.

No necesitamos sobredimensionar la infraestructura inicial.
