# 14. 🛡️ Seguridad y compliance

Esto no debería dejarse para el final.

Debemos diseñar:

### Seguridad

* MFA.
* RBAC.
* Tenant isolation.
* Encryption.
* Secrets.
* Rate limiting.
* WAF.
* Backups.
* Disaster Recovery.

### Auditoría

Registrar:

```text
Quién
Qué hizo
Cuándo
Dónde
Sobre qué entidad
Valor anterior
Valor nuevo
```

Especialmente para:

* Pagos.
* Notas.
* Matrículas.
* Planilla.
* Permisos.
* Usuarios.
