# 10. 📱 UX/UI y diseño de producto

También debemos planificar la experiencia.

No solamente:

> "Hagamos una pantalla bonita."

Debemos diseñar:

### Super Admin

```text
Dashboard
Colegios
Suscripciones
Planes
Entitlements
Billing
Auditoría
```

### Administrador del colegio

```text
Dashboard
Alumnos
Matrículas
Académico
Finanzas
RRHH
Planilla
Tienda
Actividades
Reportes
```

### Profesor

```text
Mis cursos
Mis alumnos
Notas
Asistencia
Horario
Comunicaciones
```

### Padre

```text
Mis hijos
Notas
Asistencia
Pagos
Tienda
Actividades
Comunicados
```

Y aquí debemos definir también **qué ve cada rol y cómo navega**.
