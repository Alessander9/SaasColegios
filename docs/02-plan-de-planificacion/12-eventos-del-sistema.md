# 12. 🔔 Eventos del sistema

Debemos crear un **catálogo de eventos**.

Por ejemplo:

```text
StudentCreated
EnrollmentCreated
EnrollmentConfirmed
PaymentCreated
PaymentCompleted
PaymentRefunded

OrderCreated
OrderPaid
OrderDelivered

ActivityCreated
RegistrationCreated
RegistrationPaid

GradePublished
AttendanceRecorded
PayrollProcessed
```

Esto será fundamental para nuestra arquitectura event-driven.
