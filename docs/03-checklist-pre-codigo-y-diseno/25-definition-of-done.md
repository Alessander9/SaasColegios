# 25. 🗺️ Y finalmente: Definition of Done

Cada módulo debe tener una definición objetiva.

Por ejemplo:

### "Módulo de matrículas terminado"

No significa solamente:

> "La pantalla funciona."

Significa:

```text
✓ Requerimientos
✓ UX
✓ API
✓ Database
✓ Permissions
✓ Multi-tenancy
✓ Audit
✓ Events
✓ Notifications
✓ Tests
✓ Error handling
✓ Documentation
✓ Observability
✓ Security
✓ Deployment
```
