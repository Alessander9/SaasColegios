# 23. 🏋️ Pruebas de carga

Antes de producción:

```text
100 colegios
1,000 colegios
10,000 usuarios simultáneos
```

No necesitamos llegar a esas cifras inmediatamente, pero debemos tener una estrategia para probarlas.

Especialmente:

* login;
* dashboard;
* consulta de alumnos;
* notas;
* pagos;
* tienda;
* reportes.
