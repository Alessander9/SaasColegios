# 2. 📋 Requerimientos funcionales detallados

Tenemos el mapa de módulos, pero ahora hay que convertirlo en requisitos.

Por ejemplo:

### RF-MAT-001

> El sistema debe permitir registrar una solicitud de matrícula.

### RF-MAT-002

> El sistema debe validar los documentos requeridos.

### RF-MAT-003

> El sistema debe generar automáticamente los conceptos financieros asociados.

### RF-MAT-004

> El sistema debe permitir realizar el pago.

### RF-MAT-005

> Al completar el proceso, el alumno debe quedar matriculado.

Y así con cada módulo.

Esto nos permitirá posteriormente convertir:

```text
Requisito
   ↓
Caso de uso
   ↓
API
   ↓
Pantalla
   ↓
Prueba
```
