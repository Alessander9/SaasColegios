# 19. 📈 Definir métricas de negocio

Desde el primer día debemos saber qué queremos medir.

### Plataforma

```text
MRR
ARR
Churn
CAC
LTV
Active Schools
Active Users
```

### Colegio

```text
Students
Enrollment Rate
Collection Rate
Outstanding Balance
Attendance
Academic Performance
```

### Producto

```text
Feature Usage
DAU/MAU
Module Adoption
Conversion
Errors
Performance
```

Esto nos permitirá construir posteriormente nuestro BI sin improvisar.
