# 1. 🎯 Definir exactamente qué problema resolvemos

Antes de hablar de tecnología debemos tener una definición muy clara:

> **¿Qué es la plataforma y quién la utiliza?**

Tenemos varios productos dentro de uno:

### Producto A — Plataforma SaaS

Para ti:

* Super Admin.
* Colegios.
* Suscripciones.
* Planes.
* Módulos.
* Entitlements.
* Billing.
* Soporte.
* Analytics.

### Producto B — Sistema del colegio

Para:

* Director.
* Administración.
* Secretaría.
* Contabilidad.
* RRHH.
* Profesores.

### Producto C — Portal de familias

Para:

* Padres.
* Apoderados.

### Producto D — Portal académico

Para:

* Profesores.
* Alumnos.

### Producto E — Commerce

Para:

* Tienda.
* Productos.
* Pedidos.
* Inventario.

### Producto F — Actividades

Para:

* Eventos.
* Inscripciones.
* Pagos.

Esto debería quedar escrito como **Product Vision**.
