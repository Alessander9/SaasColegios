# 15. 📐 Design System

Antes de construir 5 aplicaciones frontend, definiría:

```text
Design System
│
├── Buttons
├── Inputs
├── Tables
├── Forms
├── Modals
├── Dropdowns
├── Alerts
├── Notifications
├── Cards
├── Charts
├── Navigation
└── Data grids
```

Y reglas:

* Tipografía.
* Espaciado.
* Colores.
* Estados.
* Responsive.
* Accesibilidad.

Así:

```text
Super Admin
School Admin
Teacher
Parent
Student
```

comparten el mismo lenguaje visual.
