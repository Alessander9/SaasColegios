# 18. 💵 Modelo de costos

Esto también lo definiría antes.

Tenemos que estimar:

```text
Por colegio
├── Database
├── Storage
├── Requests
├── Emails
├── Notifications
├── Backups
├── Logs
└── Compute
```

Y calcular:

```text
Costo promedio por colegio
        ↓
Precio de suscripción
        ↓
Margen
```

Esto puede cambiar decisiones arquitectónicas.
