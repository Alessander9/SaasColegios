# 16. 🌎 Localización y configuración regional

Esto lo decidiría **antes de crear las tablas financieras**.

Aunque inicialmente trabajemos en Perú, la plataforma debería tener conceptos configurables:

```text
Country
Currency
Timezone
Locale
Date format
Number format
Tax configuration
Academic calendar
```

Porque si mañana queremos llevarlo a otro país, no queremos reescribir Finance.
