# 22. 🌱 Crear un "Demo School"

Yo crearía desde el inicio un colegio ficticio:

```text
Colegio Demo
│
├── 800 alumnos
├── 70 profesores
├── 30 administrativos
├── 20 grados/secciones
├── 10,000 pagos históricos
├── productos
├── actividades
└── información académica
```

Esto nos permitirá probar el sistema con datos realistas.
