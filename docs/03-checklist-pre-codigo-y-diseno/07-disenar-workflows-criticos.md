# 7. 🔄 Diseñar todos los workflows críticos

Antes de programar debemos tener diagramados los principales procesos.

Yo definiría como mínimo:

### Académico

* Crear año escolar.
* Crear grados.
* Crear secciones.
* Crear cursos.
* Asignar profesores.
* Registrar notas.
* Cerrar periodo.
* Registrar asistencia.

### Matrícula

* Preinscripción.
* Admisión.
* Matrícula.
* Renovación.
* Retiro.
* Traslado.

### Finanzas

* Generar pensión.
* Aplicar descuento.
* Registrar pago.
* Reembolso.
* Anulación.
* Conciliación.
* Cierre de caja.

### Tienda

* Crear producto.
* Comprar.
* Pagar.
* Reservar stock.
* Entregar.
* Devolver.

### Actividades

* Crear actividad.
* Publicar.
* Inscribir.
* Cobrar.
* Autorizar.
* Controlar asistencia.

### Planilla

* Abrir periodo.
* Calcular.
* Revisar.
* Aprobar.
* Cerrar.
* Generar documentos.
