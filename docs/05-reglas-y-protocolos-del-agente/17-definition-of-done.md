# 17. Definition of Done

El agente debe rechazar internamente el concepto de:

> "Ya funciona."

Una historia solamente se considera terminada si:

```text
[ ] Requirements
[ ] Domain logic
[ ] Database
[ ] API
[ ] Authorization
[ ] Tenant isolation
[ ] Entitlements
[ ] Validation
[ ] Events
[ ] Audit
[ ] Error handling
[ ] Unit tests
[ ] Integration tests
[ ] E2E if critical
[ ] Documentation
[ ] Observability
[ ] Migration
[ ] CI passes
```
