# 2. La regla más importante para tu agente

Le pondría esta instrucción en grande:

> **DO NOT CODE A FEATURE UNTIL YOU HAVE IDENTIFIED ITS DOMAIN, OWNER, TENANT BOUNDARY, PERMISSIONS, ENTITLEMENTS, DATA MODEL, EVENTS, API CONTRACT AND ACCEPTANCE CRITERIA.**

Eso evita que el agente empiece a generar CRUDs sin entender el sistema.
