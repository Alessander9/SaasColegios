# 25. 📌 Clasificación de módulos

Para administrar correctamente las suscripciones, los dividiría en:

### CORE — siempre disponibles

* Identidad.
* Colegio.
* Usuarios.
* Alumnos.
* Familias.
* Configuración.
* Seguridad.

### EDUCACIÓN

* Matrículas.
* Académico.
* Notas.
* Asistencia.
* Horarios.

### FINANZAS

* Pensiones.
* Pagos.
* Caja.
* Morosidad.

### RRHH

* Personal.
* Contratos.
* Planilla.

### COMERCIO

* Tienda.
* Inventario.
* Pedidos.

### ACTIVIDADES

* Eventos.
* Inscripciones.
* Cupos.
* Pagos.

### COMUNICACIÓN

* Comunicados.
* Notificaciones.

### PREMIUM / AVANZADO

* Contabilidad.
* API.
* Integraciones.
* BI avanzado.
* Automatizaciones.
