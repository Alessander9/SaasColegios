# 02. 💳 Suscripciones y Billing

## 02.1 Planes

Crear planes comerciales:

* Básico.
* Profesional.
* Enterprise.
* Personalizado.

Cada plan define:

```text
Plan
├── Módulos
├── Límites
├── Funciones
├── Precio
└── Condiciones
```

* Reactivar.
