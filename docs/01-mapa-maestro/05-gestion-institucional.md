# 05. 🏢 Gestión institucional

Cada colegio administra su estructura.

### Colegio

* Datos.
* Logo.
* Contacto.
* Dirección.
* Configuración.

### Sedes

* Sede principal.
* Sucursales.
* Campus.

### Estructura académica

```text
Nivel
 ↓
Grado
 ↓
Sección
 ↓
Aula
```

### Periodos

* Año escolar.
* Bimestres.
* Trimestres.
* Semestres.
* Periodos personalizados.

### Configuración

* Moneda.
* Zona horaria.
* Calendario.
* Escala de notas.
* Reglas de matrícula.
* Reglas de pagos.
