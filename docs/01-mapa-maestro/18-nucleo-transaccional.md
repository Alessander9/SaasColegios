# 18. 🔄 Núcleo transaccional

Este es un componente que ahora considero **fundamental**.

Todos los movimientos comerciales deben pasar por un núcleo común:

```text
                    TRANSACCIÓN
                         │
        ┌────────────────┼────────────────┐
        │                │                │
     Pensiones        Tienda          Actividades
        │                │                │
      Cuota            Pedido         Inscripción
        │                │                │
        └────────────────┼────────────────┘
                         │
                       PAGO
                         │
                    COMPROBANTE
                         │
                       CAJA
```

Esto permitirá que el sistema crezca sin duplicar lógica financiera.
