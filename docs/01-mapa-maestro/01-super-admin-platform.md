# 01. 👑 Super Admin / Platform

Este es el sistema que administras tú como propietario de la plataforma.

### 01.1 Dashboard

* Colegios activos.
* Colegios en prueba.
* Colegios suspendidos.
* Colegios vencidos.
* Alumnos totales.
* Profesores totales.
* Usuarios totales.
* Suscripciones.
* Ingresos.
* MRR/ingresos recurrentes.
* Crecimiento.
* Uso de módulos.
* Alertas.

### 01.2 Gestión de colegios

* Crear colegio.
* Editar colegio.
* Activar.
* Desactivar.
* Suspender.
* Reactivar.
* Periodo de prueba.
* Datos institucionales.
* Logo.
* Dominio/subdominio.
* Administradores.
* Contactos.
* Configuración regional.
* Configuración académica.
* Configuración financiera.

### 01.3 Administración de tenants

Cada colegio será un **tenant independiente**.

* Tenant ID.
* Estado.
* Configuración.
* Usuarios.
* Datos.
* Módulos.
* Límites.
* Suscripción.
* Auditoría.

### 01.4 Acceso de soporte

* Entrar al colegio como soporte.
* Ver configuración.
* Diagnóstico.
* Actividad.
* Historial.
* Impersonación controlada.
* Registro obligatorio de acceso.
