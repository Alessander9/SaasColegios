# 19. 🗄️ Núcleo de documentos

También conviene tener un servicio común para:

* Documentos de alumnos.
* Contratos.
* Autorizaciones.
* Boletas.
* Certificados.
* Comprobantes.
* Documentos de empleados.
* Imágenes de productos.

Con:

* Almacenamiento.
* Versionado.
* Permisos.
* Auditoría.
